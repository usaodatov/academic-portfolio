## University Projects

### MARIA — AI Technical Interview Coach

*Undergraduate Project — COM6301 | Work in progress*

MARIA is my final-year project. I'm building a system to help people prepare for technical interviews. The idea is that someone can upload their CV, practise answering questions and receive feedback.

I'm particularly interested in whether that feedback is useful and consistent when people explain the same answer in different ways. I'm still developing the system and testing different approaches.

The source code remains private while the project is under academic assessment.

### ThermoScout — Smart Campus Thermal Inspection

*Emerging Technologies — SWE6304 | Work in progress*

ThermoScout began with a question: could a small thermal sensor identify unusual heat patterns and suggest when something needs checking? The project now involves thermal monitoring, software decisions and possible drone inspection.

I'm interested in the step between identifying a problem and deciding what to do. The system is designed to check the evidence and safety conditions before a person approves an inspection. I want the technology to assist people while keeping them responsible for decisions.

The source code remains private while the project is under academic assessment.
